# 卓点 v8.9.4 — 横向き起動補助版

卓点 v8.9.3の点数計算・5段階カラー・焼き鳥・西入／北入・オフライン保存等を維持し、**横向き起動のサポート**を強化しました。

## 向きに関する仕様

- `manifest.webmanifest` の `orientation: landscape` で、対応するインストール型PWAに横画面を希望します。これは**以前から設定済み**でした。
- ホーム画面から起動したアプリで画面が縦向きの場合、対応ブラウザーでは `screen.orientation.lock('landscape')` を試します。未対応・拒否された場合に無理な回転はしません。
- 縦持ちスマホには「横向きにする」ボタンを表示します。対応するAndroidブラウザーでは全画面＋方向ロックを試します。対応していない場合は回転ロックの解除と手動回転を案内します。
- **iPhoneのSafariやホーム画面Webアプリで、Webサイトから横向きを強制することは保証できません。** OSの画面回転ロックを解除して、本体を横向きにしてください。
- 画面を物理的に回転させず、サイトだけでOSの向きを強制変更する機能ではありません。

## GitHub Pagesへの更新

1. 公開済みならまず「その他」からバックアップを保存してください。
2. このフォルダー内の `index.html`, `manifest.webmanifest`, `service-worker.js`, `firebase-config.js` とアイコンなど公開用ファイルを、リポジトリ直下に**上書き**してください。
3. 公開後、インターネット接続中にアプリを開いて再読み込みし、キャッシュを更新してください。キャッシュ名は `takuten-static-v8-9-4` です。
4. スマホのホーム画面から起動して横向き表示を確認してください。インストール済みPWAが古い向きで起動する場合、再追加が必要になることがあります。

`卓点v8.9.4-単体で試す.html` はPCの動作確認用です。ローカルファイル単体ではPWAによる起動方向指定やService Workerは検証できません。

## 共有とオフライン

複数スマホでのリアルタイム同期にはFirebaseとネット接続が必要です。端末単独のオフライン操作は引き続き対応します。実スマホでの方向ロック、共有同期、機内モード再起動は端末によって挙動が変わるため公開後に実機テストしてください。
