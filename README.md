# 卓点 v8.9.3 — 点数カラー5段階版

v8.9.2をベースに、20,000点台と30,000点台を色で区別しました。ゲームのルールや計算、座席表示、オフライン・共有の処理は変更していません。

## 点数表示の色

- 10,000点以下：**赤**（危険）
- 10,001〜19,999点：**オレンジ**（注意）
- 20,000〜29,999点：**黄色**（20,000点台）
- 30,000〜35,000点：**白**（通常）
- 35,001点以上：**緑**（目標超過）

「29,500〜30,000点」の間に端数の点数が出た場合も色が切り替わるよう、境界は30,000点にしています。34,500〜35,000点の間は白、35,000点ちょうども白です。

卓表示／一覧表示／最終結果に共通の判定を使います。開始点数30,000点、目標35,000点、西入・北入、焼き鳥、結果保存などは従来どおりです。

## 試す方法

- PCで単独試用：`卓点v8.9.3-単体で試す.html` をダブルクリックして開いてください。
- スマホ横向き・オフライン利用：公開用ファイルをGitHub Pages等のHTTPS上に配置し、初回オンラインでキャッシュ準備を確認してからホーム画面へ追加してください。
- リアルタイム共有：Firebaseの設定とネット接続が必要です。実際の4台同時接続・スマホの機内モード再起動は未検証です。

**更新時の注意**：Service Workerキャッシュ名を `takuten-static-v8-9-3` に更新しました。公開後はオンラインで再読み込みしてください。対局データは更新前に「その他 → バックアップを保存」で退避しておくと安心です。
